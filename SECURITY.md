# Security Policy

FHIRCare is an educational prototype and is not intended for clinical production use.

- Do not commit SATUSEHAT credentials.
- Do not use real production credentials in public demos.
- Do not log NIK, patient names, resource bodies or diagnostic content.
- Keep `SATUSEHAT_ENV=sandbox` in Settings unless you intentionally maintain a private deployment and have completed an appropriate security review.
- Report vulnerabilities using GitHub private vulnerability reporting when enabled on the repository.
