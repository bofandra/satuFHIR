# Contributing

1. Fork and create a focused branch.
2. Do not include real patient data or credentials in issues, fixtures, screenshots or PRs.
3. Keep clinical forms simple and keep FHIR visible through the Inspector.
4. Verify SATUSEHAT-specific profiles/terminology against current official documentation.
5. Run `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
6. Open a PR explaining the clinical action, FHIR resource(s), tests, and documentation changes.
